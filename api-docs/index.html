Spotpuls (https://spotpuls.app) provides a free, open, CORS-enabled REST API delivering official day-ahead electricity spot prices together with a dedicated regional self-learning 7-day (168 h) hourly forecast and probability range for every European spot-electricity bidding zone (Nord Pool, EPEX SPOT, OMIE, GME, TGE, OTE, OKTE, HUPX, OPCOM, IBEX, BSP, CROPEX, HEnEx, SEMOpx).

1. HOURLY SPOT + 7-DAY FORECAST ENDPOINT 
GET https://spotpuls.app/api/v1/prices?zone=FI&vat=1&currency=local&format=json
  • zone — Bidding zone code (e.g. FI, SE3, NO1, DK1, DE-LU, FR, NL, ES, IT-North, PL, GB). Default: FI.
  • vat — 1 (incl. national electricity VAT, default) or 0 (VAT 0 %).
  • currency — local (native subunit/kWh, e.g. snt, öre, øre, ct, p, gr, Ft, Kč), eur_cents (EUR c/kWh), or eur_mwh (EUR/MWh).
  • format — json (default), csv (Google Sheets / Excel), or badge (live embeddable SVG widget).
2. DISCOVER ALL 40 BIDDING ZONES 
GET https://spotpuls.app/api/v1/zones
GET https://spotpuls.app/api/v1/prices?list=zones

JAVASCRIPT / TYPESCRIPT FETCH EXAMPLE 
const res = await fetch("https://spotpuls.app/api/v1/prices?zone=SE3&vat=1");
const data = await res.json();
console.log(data.current.spotPrice, data.meta.unit);
console.log("Next 168h series:", data.series.length);
PYTHON / DATA SCIENCE EXAMPLE 
import requests
r = requests.get("https://spotpuls.app/api/v1/prices", params={"zone": "DE-LU", "vat": 1})
payload = r.json()
for slot in payload["series"][:24]:
    print(slot["timestamp"], slot["spotPrice"], slot["isForecast"])
