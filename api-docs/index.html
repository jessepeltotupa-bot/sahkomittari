Spotpuls (https://spotpuls.app) provides a free, zero-key, CORS-enabled REST & automation API delivering official day-ahead electricity spot prices together with an empirically calibrated 7-day (168 h) Log-Merit + Hist-GBDT hourly forecast (including negative price regimes and conformal probability bands) across all 40 European bidding zones. Ten native output formats allow direct integration into smart-home hubs, relays, EV chargers, microcontrollers, calendars, spreadsheets, monitoring stacks, and websites.

1. HOURLY SPOT + 7-DAY FORECAST + SMART AUTOMATION 
GET https://spotpuls.app/api/v1/prices?zone=FI&vat=1&window=3&format=json
  • zone — Any of 40 European zones (FI, SE1..SE4, NO1..NO5, DK1..DK2, EE, LV, LT, DE-LU, FR, NL, ES, IT-North, PL, GB).
  • vat — 1 (incl. national electricity VAT, default) or 0 (VAT 0 %).
  • currency — local (snt, öre, øre, ct, p, gr, Ft, Kč), eur_cents, eur_kwh, or eur_mwh.
  • window — 1..24 (default 3): computes cheapestContiguousWindow and cheapestHours for relays, boilers, heat pumps, and EVs.
  • margin / transfer / threshold — Optional contract add-ons & price trigger threshold.
  • format — json, compact (shelly), ha, evcc, victron, csv, ical, prometheus, plain, badge, or widget.

SHELLY PLUS / GEN2 / GEN3 / PRO LOCAL RELAY SCRIPT (< 500 B) 
// Runs on Shelly Plus 1PM / Pro 3EM — switches relay ON during cheapest 3h window
const URL = "https://spotpuls.app/api/v1/shelly/FI.json?window=3";
function pollSpotpuls() {
  Shelly.call("HTTP.GET", { url: URL, timeout: 10 }, function (res, err) {
    if (err || !res || res.code !== 200) return;
    const d = JSON.parse(res.body);
    const shouldRun = d.runContig === 1; // or d.runCheap === 1
    Shelly.call("Switch.Set", { id: 0, on: shouldRun });
  });
}
pollSpotpuls();
Timer.set(300000, true, pollSpotpuls);
